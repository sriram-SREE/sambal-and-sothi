SELF-HOSTED FONTS DIRECTORY (GDPR Compliance)
==============================================
Place Cormorant Garamond and Jost .woff2 / .woff files in this folder.
- cormorant-garamond.woff2
- jost.woff2
These are declared in assets/css/theme.css using @font-face rules.
By serving fonts locally, no IP addresses of EU visitors are shared with Google Fonts CDN.
